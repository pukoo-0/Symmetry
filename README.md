# Point Group Finder

Drop in an `.xyz` file and get the molecule's point group (Schoenflies symbol), its classes of symmetry
operations as in a character table, every rotation axis, mirror plane and inversion centre drawn on the
molecule, and an animation of each operation.

Runs entirely in the browser: Python (Pyodide + NumPy) is downloaded once, and files never leave the
visitor's computer. No pymatgen needed.

## Deploy

**Streamlit Community Cloud:** new app, pick this repository, main file path **`streamlit_app.py`**.

**GitHub Pages (optional, loads faster):** Settings → Pages → branch `main`, folder `/docs`.

## What it shows

| Part | Contents |
|---|---|
| Result | Point group, classes of operations (character-table header), order h, counts of axes and planes, tolerance |
| 3D view | Ball and stick, sticks or space filling; axes and planes coloured by type; atoms on the shown element marked |
| Animation | Any operation of the group, with start positions shown faintly; S operations in two steps |
| Elements | Every axis, plane and centre, the atoms on it, and how well it fits (Å) |
| Operations | Every operation with a plain description and its fit |
| Tolerance | The point group at nine tolerances from 0.01 to 1 Å, so you can see whether the answer is stable |
| Atoms | Coordinates with the centre of mass at the origin, and the elements each atom lies on |

Downloads: a report with every operation and its fit (.txt), the centred coordinates (.xyz), and a picture.

## Method

1. Move the centre of mass to the origin. Group atoms that could be swapped by symmetry
   (same element, same distance from the centre).
2. Candidate axes: principal axes of inertia, directions to atoms, midpoints of pairs, normals of
   rings of equivalent atoms. Candidate mirror normals: principal axes and differences of atom pairs.
   Candidates come from three reference atoms that span space, so their number stays small.
3. Possible axis orders n must divide the size of every ring of equivalent atoms around the axis.
4. An operation counts when every atom lands within the tolerance of an atom of the same element, one to
   one. If a candidate nearly works, the exact operation for that atom permutation is fitted by least
   squares (Kabsch) and tested again, so noise in the coordinates does not hide symmetry.
5. The whole group is generated by multiplying atom permutations (exact), and each operation's matrix is
   fitted to the atoms. The group is named from its axes, planes, inversion centre and S axes, and checked:
   the number of operations must equal the order of the named group.
6. Classes are the conjugacy classes {g x g⁻¹} of the group, labelled with the original app's names
   (C2', C2'', σv, σd, σh …), so the header matches standard character tables
   (for example Oh: E, 6C4, 8C3, 6C2, 3C2 (=C4²), i, 8S6, 6S4, 3σh, 6σd).

Checked by the tests: all 43 crystallographic and common molecular point groups (C1 to Ih, including
S4, S6, S8, Dnd up to D6d, T, Th, O, I) built from their exact operations and randomly rotated; a set
with 0.02 Å noise; and real molecules against character tables (water, ammonia, methane, ethane, allene,
benzene, SF6, cubane, adamantane, C60, CO2).

## Files

```
streamlit_app.py      ← the file Streamlit runs (serves docs/index.html)
docs/index.html       ← the finished web app (built, do not edit by hand)
symmetry_core.py      ← point-group detection, labelling and reports (NumPy only)
web/bridge.py         ← connects the page to symmetry_core
web/index.src.html    ← the page's source (HTML, CSS, JavaScript)
build_web.py          ← builds docs/index.html from the files above
examples/             ← eleven small molecules with known point groups
tests/                ← pytest checks; tests/groups.py builds molecules of any point group
legacy/               ← the original pymatgen + Streamlit app
```

After changing `symmetry_core.py`, `web/bridge.py`, `web/index.src.html` or the examples:

```
python build_web.py
pytest
```

then commit `docs/index.html` as well.
